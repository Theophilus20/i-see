# Brand

The logo is `mark.png` (the round mark) next to the name "I SEE". To replace the whole logo with
one image, drop it here as `logo.svg` (preferred) or `logo.png`; `Logo.tsx` picks it up.
The browser-tab icons are `public/favicon.png`, `public/favicon-32.png`, `public/apple-touch-icon.png`
and `public/icon-192.png`.
